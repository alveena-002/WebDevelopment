# Day 01 - Node.js & Express Setup

This project is a basic Node.js and Express.js setup created as part of Day 01 backend development training.

## 🚀 Technologies Used

- Node.js
- npm
- Express.js
- Supabase

## 📌 What I Did

- Installed Node.js and npm.
- Initialized a new Node.js project using `npm init`.
- Installed Express.js using npm.
- Created a basic Express server.
- Created a GET route `/`.
- Configured the server to run on port `3000`.
- Tested the server in the browser.
- Created a Supabase project.
