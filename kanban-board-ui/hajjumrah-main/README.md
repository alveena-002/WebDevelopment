# Hajj Umrah Tours — Luxury Pilgrimage Travel Website

A premium, luxury-tier marketing website for Hajj Umrah Tours, a Hajj & Umrah pilgrimage travel company serving clients in the United States, United Kingdom, and Pakistan.

## About This Project

This is a front-end marketing website featuring luxury travel package information, hotel and transportation showcases, personalized ziyarat experiences, and a client inquiry system. The design uses a custom gold-and-ink color palette with an Islamic geometric star-pattern motif as a signature visual element throughout.

## Tech Stack

- **Framework:** Next.js (App Router)
- **Styling:** Tailwind CSS
- **Language:** TypeScript
- **Package Manager:** pnpm

## Project Structure

```
├── app/            # Next.js app router pages
├── components/     # Reusable UI components
├── lib/            # Utility functions and helpers
├── public/         # Static assets (images, icons)
├── components.json # shadcn/ui configuration
└── next.config.mjs # Next.js configuration
```

## Getting Started

### Prerequisites

- Node.js 18+
- pnpm (or npm/yarn)

### Installation

```bash
# Clone the repository
git clone https://github.com/kamalalveena-droid/hajjumrah.git
cd hajjumrah

# Install dependencies
pnpm install

# Run the development server
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

## Pages Included

- Home
- About Us
- Services / Packages
- Hotels (Makkah & Madinah)
- Gallery
- Contact Us

## Before Going Live — Checklist

This project currently uses placeholder content in several places. Before deploying to production, make sure to:

- [ ] Replace all `[INSERT ...]` placeholder text with real company details (contact info, addresses, team bios, package pricing)
- [ ] Replace AI-generated / placeholder hotel and skyline images with real, licensed photography — especially any imagery near sacred sites (Kaaba, Masjid al-Haram, Masjid an-Nabawi)
- [ ] Replace placeholder testimonials with real, verified client reviews
- [ ] Connect the contact/inquiry forms to a real email or database service
- [ ] Review all legal pages (Privacy Policy, Terms & Conditions) with a qualified legal professional
- [ ] Add real social media links and business contact numbers (USA / UK / Pakistan offices)
- [ ] Set up analytics
- [ ] Connect a custom domain

## Deployment

This project is deployed via Vercel. Any push to the `main` branch will automatically trigger a new production deployment.
